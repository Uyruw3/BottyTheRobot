# Botty — índice de proyectos

Botty es el mismo compañero expresivo en dos ediciones, publicadas ahora en
repositorios independientes. El desarrollo de Windows está separado del robot
físico Raspberry Pi.

| Proyecto | Descripción | Repositorio |
| --- | --- | --- |
| **Botty Desktop** | Ojos animados, conversación, memoria local y voz opcional para Windows. | [Uyruw3/BottyDesktop](https://github.com/Uyruw3/BottyDesktop) |
| **Botty Robot** | Edición física de Botty para Raspberry Pi: voz, visión, sensores, movimiento y dashboard, además de una consola de pruebas de hardware. | [Uyruw3/BottyRobot](https://github.com/Uyruw3/BottyRobot) |

## Releases

- [Botty Desktop v0.2.0](https://github.com/Uyruw3/BottyDesktop/releases/tag/v0.2.0)
- [Botty Robot v0.2.0](https://github.com/Uyruw3/BottyRobot/releases/tag/v0.2.0)

Consulta cada repositorio para sus instrucciones de instalación, dependencias
opcionales, pruebas, funcionamiento de IA y avisos de seguridad. Los dos
proyectos son experimentales; el uso del hardware requiere revisar el
cableado y la alimentación antes de encender los motores.

## Sitio web

La [página de Botty](https://uyruw3.github.io/BottyTheRobot/) explica cómo
funciona, presenta las dos ediciones y enlaza sus repositorios y Releases.
