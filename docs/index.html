02 / HARDWARE⌁

PARA RASPBERRY PI

Botty Robot Hardware

Un controlador independiente para probar motores, sonar y buzzer desde una consola sencilla. Los movimientos son breves y temporizados, y el modo simulación permite probar sin GPIO.

  • GPIO
  • Motores
  • Simulación

PARA WINDOWS

Botty Desktop

Un compañero de escritorio con ojos animados, conversación y memoria local. Incluye opciones para voz y lectura de pantalla cuando instalas sus dependencias adicionales.

  • Conversación
